# Week 01 — Intermediate / Advanced SQL

## Objective

Strengthen SQL reasoning by solving business questions with the **Northwind** database.

## Topics

- Common Table Expressions (CTEs)
- Simple and correlated subqueries
- EXISTS
- CASE
- Date operations
- UNION

## Target

Complete **15–20 business-oriented queries**.

## Study Rules

1. Write the business question before writing SQL.
2. Attempt the query before looking for help.
3. Keep notes about mistakes and important discoveries.
4. Be able to explain why the final query works.
5. Prefer clear and maintainable SQL.

## Files

- `queries.sql` — exercises and solutions
- `notes.md` — mistakes, concepts and review points
