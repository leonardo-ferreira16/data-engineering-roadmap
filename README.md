# Data Engineering Roadmap

My practical roadmap for transitioning into **Data Engineering**, documenting study, exercises, projects, architecture decisions, and production-oriented learning.

## 🎯 Goal

Build, operate, and explain end-to-end data pipelines — from ingestion and storage to transformation, orchestration, quality, and analytics consumption.

## 🗺️ 6-Month Roadmap

| Month | Main focus |
| --- | --- |
| 1 | Advanced SQL, Python for pipelines, Data Engineering fundamentals |
| 2 | Relational & dimensional modeling, ETL/ELT, Docker |
| 3 | Cloud, Data Lake, Parquet, Warehouse & Lakehouse |
| 4 | Apache Airflow, dbt, orchestration & transformation |
| 5 | Distributed systems, PySpark & Spark optimization |
| 6 | Kafka, streaming, data quality, Terraform, CI/CD & final project |

## 🧰 Target Stack

**Languages:** Python, SQL  
**Database:** PostgreSQL  
**Storage:** Data Lake, Parquet  
**Cloud:** Azure / Microsoft Fabric  
**Orchestration:** Apache Airflow  
**Transformation:** dbt  
**Big Data:** PySpark  
**Streaming:** Apache Kafka  
**Infrastructure:** Docker, Terraform, GitHub Actions  
**Analytics:** Power BI

## 🧠 Learning Method

- 30% theory / 70% hands-on practice
- Every topic should produce code, documentation, or a project
- Study through business problems, not only syntax
- A topic is considered mastered when I can explain and implement it without relying on notes
